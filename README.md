**Ishga tushirish:** `run.bat` (batafsil: ilova ichidagi *Yo'riqnoma* yoki `docs/setup/00-boshlash.md`).

- `docs/TZ.md` — texnik topshiriq · `docs/CLAUDE.md` — dasturlash qoidalari · `docs/CONTRACTS.md` — shartnomalar (v1.0 farqlari oxirida)
- `docs/DECISIONS.md`, `docs/PROGRESS.md` — qarorlar va holat · `docs/setup/` — ulanishlar yo'riqnomasi
- Test: `pip install -r requirements-dev.txt && python -m pytest`
