# Nima qilsam? (tezkor javoblar)

Eng ko'p uchraydigan vaziyatlar — bir qatorda javob. Batafsil yo'riqnomalar rol bo'yicha alohida bo'limlarda.

| Vaziyat | Nima qilish kerak |
|---|---|
| Yangi post qo'yishim kerak | Pastdagi qizil **+** tugma (kompyuterda: Kontent kalendar → «Yangi kontent») → platformani tanlang: Telegram, Instagram yoki YouTube |
| Rasm Instagramga sig'madi / qirqilib ketdi | Formada «Media o'lchami» ni tanlang (Instagram uchun 4:5), o'ng tomondagi ko'rinishda rasmni sudrab siljiting, g'ildirak yoki sliderdan kattalashtiring |
| Katta video yuklash kerak | Videoni oddiy tanlang — tizim uni Cloudflare'ga avtomatik joylaydi. Holatini «Cloudflare» menyusida ko'rasiz |
| Fayl allaqachon yuklangan | Formada «☁ Cloudflare'dan tanlash» tugmasi |
| Post xato bilan chiqmadi | Kontent kartasini oching → «Tarix» va qizil xato matnini o'qing → «Xatolarni qayta urinish» |
| Keraksiz postni o'chirish | Kontent kartasida «O'chirish (savatga)». 30 kun ichida «Savat» menyusidan tiklash mumkin |
| Kim nima qilganini bilish | «Faoliyat jurnali» (menejer/admin), yoki kontent kartasidagi «Tarix» |
| Mijozga hisobot yubormoqchiman | Hisobotlar → yaratish. Mijoz uni Telegram bot orqali oladi |
| Instagram «Graph xatosi» chiqdi | Xato matnidagi tavsiyani o'qing (token muddati, akkaunt turi, rasm o'lchami) — Ulanishlar → «Qayta ulash» |
| Parolni unutdim | Admin: Foydalanuvchilar → parolni tiklash |
| Hech narsa ishlamayapti | «Tizim holati» sahifasini oching — qaysi xizmat qizil ekanini ko'rsatadi |

> Maslahat: telefonda pastki menyudan foydalaning: Kalendar · Cloudflare · **+** · Tahlil · Menyu.
