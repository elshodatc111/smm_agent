# 12. Kompyuter yoqilganda tizim o'zi ishga tushishi

1. Loyiha papkasida `autostart.bat` ni **bir marta** ikki marta bosing. Administrator ruxsatini so'raydi — «Ha» deng.
2. U Windows «Task Scheduler» ga vazifa qo'shadi: kompyuter yoqilganda (hech kim kirmasa ham, 45 soniyadan keyin) tizim o'zi ishga tushadi, to'xtab qolsa 1 daqiqada qayta ko'tariladi, kompyuter uyquga ketmaydi (tarmoqdan ishlaganda).
3. Tekshirish: `autostart.bat status`. O'chirish: `autostart.bat remove`.
4. Vaqtincha to'xtatish: `stop.bat` (keyingi yoqishda yana o'zi ishga tushadi).

Eslatma: kompyuter noutbuk bo'lsa, quvvat adapterida qoldiring. Elektr o'chib qolsa — yoqilgach tizim o'zi ko'tariladi.
