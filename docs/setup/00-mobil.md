# Telefon va planshetda ishlash

Platforma telefonda to'liq ishlaydi. Pastda doimiy menyu bor:

| Tugma | Vazifasi |
|---|---|
| Kalendar | Rejadagi postlar (ro'yxat ko'rinishida) |
| Cloudflare | Fayllar va ularning holati |
| **+** (qizil) | Yangi post |
| Tahlil | Platforma statistikasi |
| Menyu | Qolgan hamma bo'limlar |
